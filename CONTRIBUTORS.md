# Contributors

Thank you to everyone who has helped phasewise. Being listed here is entirely
optional: add yourself in your pull request if you want to, leave this file
alone if you do not. Nobody is added on someone else's behalf, and you can ask
to be removed at any time.

Your Git history and the release notes credit your commits whether or not you
are listed here.

## How to add yourself

Add one line to the list below, in alphabetical order by name:

```
- Your Name ([@github-login](https://github.com/github-login)): what you did, in a few words
```

The link is optional (a name alone is fine), and so is the description. Use
whatever name you like.
